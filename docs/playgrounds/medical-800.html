This playground has moved

The medical 800-page Web Worker showcase has been replaced by the Scale playground, which does everything this page did and goes considerably further:

  • 1,000 to 100,000 pages instead of 100 to 10,000 — the 10,000-page preset lives on there.
  • Streams with buildDocumentPDFStreamTrue, which never joins the PDF binary. This page used buildDocumentPDFStream, which does — and therefore could not have reached 100,000 pages at any content density.
  • Reports the page count it measured in the output bytes, and shows an honest indeterminate state during assembly instead of a progress bar derived from a hardcoded bytes-per-page guess.
  • Offers three output sinks, including writing straight to disk so the document never passes through page memory.
